# Raw Data – Foremost

This folder contains the raw environmental sensor datasets collected at the **Foremost** monitoring location and used in the capstone project.

The folder contains four datasets, organized according to the environmental variables recorded by the monitoring station.

## Datasets

| File                        | Description                                           |
| --------------------------- | ----------------------------------------------------- |
| `* AGDM`                    | Contains soil moisture measurements.                  |
| `*_AGDM`                    | Contains soil temperature measurements.               |
| `*_air_temp_precip`         | Contains air temperature and precipitation variables. |
| `*_humidity_wind_radiation` | Contains humidity, wind, and radiation variables.     |
