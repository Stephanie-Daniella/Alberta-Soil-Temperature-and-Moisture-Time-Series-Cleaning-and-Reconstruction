# Review

This folder contains the quantitative review and comparison of the environmental sensor datasets before and after the cleaning and imputation procedures.

The purpose of this folder is to provide a consolidated assessment of the characteristics of the datasets and to document the effect of the different cleaning criteria on the observations.

## Contents

The analyses in this folder include summaries for the different sensors and study locations, both before and after the cleaning process.

The main characteristics reported include:

* Minimum values
* Mean values
* Maximum values
* Number of missing observations
* Total number of original observations
* Number of observations removed during cleaning
* Number of remaining observations after cleaning
* Comparison between the Z-score and percentile-based cleaning criteria

## Raw Data Review

The initial review describes the characteristics of the original sensor datasets before any cleaning or imputation procedures were applied.

This includes descriptive statistics and the number of missing observations for each sensor and study location.

These summaries provide a baseline for evaluating the changes introduced by the subsequent cleaning procedures.

## Cleaning Review

The cleaning review summarizes the effect of the anomaly detection procedures on the datasets.

For each sensor and study location, the number of observations identified and removed using the Z-score and percentile-based criteria is reported.

This allows the two cleaning approaches to be quantitatively compared and provides a record of the extent to which each criterion modified the original datasets.
